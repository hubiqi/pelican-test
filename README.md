# 鹈鹕测试 · The Pelican Test

> 人类自古以来就痴迷于画鹈鹕骑自行车。

一支约 **2:17** 的代码生成动画短片：一只鹈鹕骑着自行车，沿一条贯穿全片的路，依次穿过
**20 个不同时代、不同地域、不同艺术风格**的版块，每过一道画框就换一种画风。

画面全部由 JavaScript（p5.js）逐帧绘制，不使用任何外部图片 / 影片 / 音频素材。
音乐全部程序合成（阶段 4）。

用来验证：时间轴、节拍、镜头、穿框、木偶动作连续性、结尾展墙。

## 时间轴（120 BPM，一小节 2 秒）

```
0 ─────────── 5 ─────────────────────────────────────────── 125 ───── 137
   Intro 5s      20 × 6s（每个版块 3 小节）                    Outro 12s
   2.5 小节                                                 6 小节
```

- 第 k 个版块的起止：`5 + (k-1)*6` → `5 + k*6`
- 第 k 道画框（进入第 k 格）的强拍：`5 + (k-1)*6`
- 脚踏一圈 = 两拍 = 1 秒；车轮与脚踏 1:1
- 每小节内部：第 1 小节进场，第 2 小节是本版的梗 / 高光，第 3 小节骑向下一道框

时间基准全部在 `src/beat.js`，任何地方都用绝对时间 `t`（秒）求值。

## 画面坐标约定

每个版块在 **1000 × 1000 的设计方格**里作画，输出 **1920×1080**。
方格按 `cover` 缩放（×1.92）铺满画面，上下各裁掉 218.75 单位：

```
设计方格 y=0 ─────────────── 被裁
        y=218.75 ─────────── 画面顶（安全带从这里开始）
        y=562.5  ─────────── 画面中线
        y=781.25 ─────────── 画面底（安全带到这里结束）
        y=1000 ───────────── 被裁
```

**关键信息请留在 y ∈ [219, 781] 的安全带内**（`kit.SAFE_TOP` / `kit.SAFE_BOTTOM`）。
默认地面线 `kit.GROUND_Y = 690`。

## 镜头

20 幅画并排挂在同一条走廊上，每幅宽 1920（正好一屏），第 k 幅的中心在世界坐标 `k*1920`。

- 一个版块里镜头基本**停住**，只做极轻的漂移 —— 画面稳，细节看得清
- **穿框**：在画框所在的那一拍，镜头用一个 0.72 秒的缓动从上一格滑到下一格，
  滑动中点正好落在强拍上，同时推近 5.5%（`camera.state().zoom`）
- 穿框时两幅画同时绘制，于是你看到画面被画框切开、从中间穿过去

## 运行

```bash
npm install          # p5 / p5.brush / puppeteer-core
npm run serve        # → http://127.0.0.1:8200/public/index.html
```

预览页参数：

| 参数 | 作用 |
|---|---|
| `?t=8.2` | 定格在 8.2 秒（并自动暂停） |
| `&play=0` | 加载后暂停 |
| `&ui=0` | 隐藏底部控制条（抓图用） |
| `&hud=1` | 左上角显示 t / 版块 / fps / 镜头 |
| `&dpr=0.5` | 低分辨率预览（手机上更流畅） |

接触表：

```
http://127.0.0.1:8200/public/sheet.html?t=2,8,14,20&cols=4&w=480
http://127.0.0.1:8200/public/sheet.html?every=6&from=8.3&to=120&cols=4&w=420
```

## 出片（需要桌面 Chrome + ffmpeg）

```bash
node tools/shot.mjs 8.2 out/hero.png                     # 抓单帧
node tools/shot.mjs --sheet "2,8,14,20" out/sheet.png    # 抓接触表
node tools/render.mjs --fps 60 --from 0 --to 137 --out frames
FPS=60 CRF=18 sh tools/encode.sh frames out/pelican.mp4 audio/mix.wav
```

> 本机（Android / PRoot）没有可用内存跑无头 Chromium，所以预览与自查走内置浏览器截图 +
> `sheet.html` 接触表；`tools/*.mjs` 是给桌面环境用的标准管线。
